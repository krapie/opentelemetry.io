## 버전 지원 {#version-support}

.NET용 오픈텔레메트리는 [.NET](https://dotnet.microsoft.com/download/dotnet)과
[.NET Framework](https://dotnet.microsoft.com/download/dotnet-framework)의 공식
지원 버전을 모두 지원하며, .NET Framework 3.5 SP1은 예외이다.

## 시그널 {#signals}

OpenTelemetry .NET은 다음 시그널을 지원한다.

- [트레이스](/docs/languages/dotnet/traces): .NET 애플리케이션에서 분산
  트레이스를 수집하는 방법을 알아본다.
- [메트릭](/docs/languages/dotnet/metrics): .NET 애플리케이션에서 메트릭을
  수집하는 방법을 알아본다.
- [로그](/docs/languages/dotnet/logs): .NET 애플리케이션에서 로그를 수집하는
  방법을 알아본다.

## 저장소 {#repositories}

OpenTelemetry .NET은 다음 저장소로 구성된다.

- [OpenTelemetry .NET](https://github.com/open-telemetry/opentelemetry-dotnet)
- [OpenTelemetry .NET Contrib](https://github.com/open-telemetry/opentelemetry-dotnet-contrib)
- [OpenTelemetry .NET Automatic Instrumentation](https://github.com/open-telemetry/opentelemetry-dotnet-instrumentation)
