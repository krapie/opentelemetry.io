Java를 위한 제로 코드 계측(Zero-code instrumentation)의 일반적인 옵션으로는 Java
에이전트(agent) JAR, Spring Boot Starter, Quarkus OpenTelemetry Extension이
있다. 서비스나 애플리케이션 코드를 수동으로 계측하는 방법을 알아보려면
[수동 계측](/docs/languages/java/instrumentation/)을 참고한다.
