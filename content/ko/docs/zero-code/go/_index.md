Go를 위한 제로 코드 계측(Zero-code instrumentation)은 코드 변경 없이 모든 Go
애플리케이션을 계측하고 다양한 인기 라이브러리 및 프레임워크로부터 텔레메트리
데이터를 수집(collect)할 수 있는 방법을 제공한다.

이 프로젝트는 현재 진행 중이며, 더 자세히 알아보려면
[opentelemetry-go-instrumentation 저장소](https://github.com/open-telemetry/opentelemetry-go-instrumentation/)를
방문한다.
