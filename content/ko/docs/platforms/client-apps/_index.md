클라이언트 사이드 애플리케이션은 서버 사이드 워크로드와 비교했을 때 옵저버빌리티
측면에서 고유한 과제를 안고 있다. 이러한 앱은 사용자가 직접 제어할 수 없는
기기에서 실행되며, 네트워크 상태, 하드웨어 성능, 사용자 행동도 제각각이다.

## 클라이언트 사이드 옵저버빌리티가 중요한 이유 {#why-client-side-observability-matters}

기존의 서버 사이드 모니터링은 백엔드 시스템에 대한 가시성(visibility)을
제공하지만, 사용자 경험의 전체 그림은 파악하지 못한다. 클라이언트 사이드
옵저버빌리티는 다음을 도와준다.

- **실제 사용자 경험 이해**: 사용자가 실제로 체감하는 로드 시간, 프레임 속도,
  응답성을 확인한다.
- **컨텍스트 안에서 문제 디버깅**: 오류를 기기 특성, 네트워크 상태, 사용자
  행동과 연관 짓는다.
- **엔드투엔드(end-to-end) 트랜잭션 추적**: 클라이언트 사이드 오퍼레이션을
  백엔드 트레이스와 연결해 완전한 분산 트레이싱을 구성한다.
- **대규모 앱 상태 모니터링**: 사용자 기반 전반의 텔레메트리를 집계해 패턴과
  추세를 파악한다.

## 서버 사이드 계측과의 주요 차이점 {#key-differences-from-server-side-instrumentation}

클라이언트 앱을 계측할 때는 다음 요소를 고려한다.

- **리소스 제약**: 모바일 기기와 브라우저는 CPU, 메모리, 배터리가 제한적이다.
  텔레메트리 수집은 효율적이어야 하며 앱 성능에 영향을 주지 않아야 한다.
- **네트워크 가변성**: 사용자는 느리거나, 간헐적이거나, 아예 연결되지 않은
  환경에 있을 수 있다. 네트워크 불안정성에 대처하기 위해 오프라인 버퍼링과 배치
  내보내기(batch export)를 구현한다.
- **세션 관리**: 관련 텔레메트리를 그룹화하고 여러 앱 실행에 걸친 사용자
  여정(user journey)을 이해하기 위해 사용자 세션을 추적한다.
- **개인정보 보호 및 동의**: 클라이언트 앱은 개인정보 보호 규정의 적용을 받는
  데이터를 수집하는 경우가 많다. 데이터 최소화, 동의 관리, 속성 편집(attribute
  redaction)을 계획한다.
- **데이터 양**: 사용자가 수백만 명에 이를 수 있으므로, 대표성 있는 텔레메트리를
  유지하면서 비용을 관리하려면 샘플링 전략이 필수적이다.

## 실사용자 모니터링(Real User Monitoring, RUM) {#real-user-monitoring-rum}

오픈텔레메트리는 실제 사용자가 애플리케이션을 어떻게 경험하는지 포착하는
실사용자 모니터링(Real User Monitoring, RUM) 패턴을 지원한다.

- **페이지/화면 로드 성능**: 첫 바이트까지의 시간(Time to first byte), 최초
  콘텐츠풀 페인트(first contentful paint), 전체 로드 완료 시간.
- **사용자 상호작용**: 클릭 이벤트, 내비게이션 패턴, 폼 제출.
- **오류 및 크래시**: 처리되지 않은 예외(unhandled exception), ANR 이벤트, 오류
  발생률.
- **리소스 로딩**: 네트워크 요청 시간, 캐시 적중률(cache hit rate), 리소스 크기.

## 백엔드와 연결하기 {#connecting-to-your-backend}

클라이언트 텔레메트리는 백엔드 트레이스와 연결될 때 가장 큰 가치를 발휘한다.
엔드투엔드 가시성을 유지하려면 HTTP 요청을 통해 트레이스 컨텍스트를 전파한다.

```text
Client App → API Gateway → Backend Services → Database
    │              │              │              │
    └──────────────┴──────────────┴──────────────┘
                 Correlated Traces
```

클라이언트 SDK가 트레이스 헤더(`traceparent`, `tracestate`)를 주입하도록
설정하고, 백엔드 서비스가 자신의 오퍼레이션 전반에 걸쳐 이 컨텍스트를 전파하도록
한다.
