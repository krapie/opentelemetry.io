## 매니저 규칙 {#manager-rules}

### ReconcileErrors

|      |                                                                                                                                             |
| ---: | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 의미 | 오픈텔레메트리 오퍼레이터가 조정(reconciliation) 단계를 성공적으로 완료하지 못한다. OpenTelemetryCollector 구성이 잘못되었을 가능성이 크다. |
| 영향 | 이미 실행 중인 배포나 새로 생성되는 정상적인 배포에는 영향이 없다.                                                                          |
| 진단 | 매니저 로그에서 원인을 확인한다.                                                                                                            |
| 완화 | 오류를 일으키는 OpenTelemetryCollector를 찾아 구성을 수정한다.                                                                              |

### WorkqueueDepth

|      |                                                                                    |
| ---: | ---------------------------------------------------------------------------------- |
| 의미 | 오퍼레이터의 작업 큐(working queue) 깊이가 0보다 크다.                             |
| 영향 | 큐 깊이가 빠르게 0으로 돌아오면 영향이 없다. 문제가 지속되면 추가 조사가 필요하다. |
| 진단 | 매니저 로그에서 원인을 확인한다.                                                   |
| 완화 | 다양한 오류가 원인일 수 있다. 로그에 표시되는 내용을 바탕으로 대응한다.            |
