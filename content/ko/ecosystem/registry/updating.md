[레지스트리](..) 항목과 외부 링크 등의 [목록 데이터][list data]를 주기적으로
검토하여, 오픈텔레메트리를 실제로 지속적으로 지원하는
[도입 기업](../../adopters/), [배포판](../../distributions/),
[통합, 라이브러리](../../integrations/), [벤더](../../vendors/)만 레지스트리에
포함되도록 한다.

항목 작성자는 활성 상태이며 최신인 배포판, 문서, 라이브러리에 대한 링크를 유지할
것을 권장한다. 더 이상 오픈텔레메트리를 실제로 지원하지 않는 것으로 보이는 구성
요소의 항목은 업데이트하거나 삭제할 권리를 보유한다. 예를 들어 외부 링크가
유효하지 않게 된 경우 이런 일이 발생할 수 있다. 원본 항목 데이터를 제출한 GitHub
사용자에게 최선을 다해 연락을 시도하지만, 그렇지 않은 경우에도 항목과 항목
데이터를 편집하고 삭제할 권리를 보유한다.

[list data]:
  https://github.com/open-telemetry/opentelemetry.io/tree/main/data/ecosystem
